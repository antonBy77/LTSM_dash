# LSTM Neuro Forecast

Проект представляет собой Dash-приложение для прогнозирования финансовых временных рядов с использованием LSTM-моделей.

## Описание

Приложение позволяет загружать исторические данные по финансовым инструментам (с использованием yfinance), строить графики с индикаторами (ATR, Bollinger Bands), прогнозировать будущие значения с помощью предварительно обученных LSTM-моделей и оценивать риски (VAR, ATR, волатильность).

## Функциональность

*   Загрузка данных с Yahoo Finance.
*   Расчет индикаторов: ATR, Bollinger Bands.
*   Прогнозирование с использованием LSTM.
*   Оценка рисков: VAR, ATR, волатильность.
*   Интерактивный веб-интерфейс (Dash).
*   Выбор модели.
*   Настройка параметров.

## Установка

1.  **Клонируйте репозиторий:**

    ```bash
    git clone <repository_url>
    ```

2.  **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

3. **Запустите приложение**
    ```bash
     python app.py
    ```

## Использование

1.  Запустите приложение.
2.  Введите тикер, начальную и конечную даты, интервал.
3.  Нажмите кнопку "Update".
4.  Выберите модель (необязательно).
5.  Настройте параметры в таблице настроек.

## Структура проекта

*   `app.py`: Основной файл приложения (Dash).
*   `config.py`: Конфигурация (тикер, даты, интервал и т.д.).
*   `data_loader.py`: Загрузка и подготовка данных.
*   `indicators.py`: Расчет индикаторов.
*   `predictor.py`: Прогнозирование.
*   `requirements.txt`: Зависимости.
*   `Dockerfile`: Dockerfile для контейнеризации.
